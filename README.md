# Repository Overview

This repository contains three folders:

## `geometry_with_graphics`

This folder contains a collection of math problems I found on YouTube. For each one, I provide a Python solution that uses graphics and, in some cases, a “guessing” strategy that I think is fun.

## `monte_carlo_method`

This folder contains solutions to math problems found on YouTube. Each solution uses the Monte Carlo method.

## `project_euler`

This folder contains Python solutions to some of the Project Euler problems.

Project Euler: `https://projecteuler.net`

Project Euler includes nearly 1,000 math and programming problems. The early problems are not too difficult, but they become much more challenging as you go. Some of them are a bit out of my wheelhouse, but I plan to keep plugging away.

## `math_net`

A great collection of problems from various sources put together by MIT.

https://mathnet.csail.mit.edu
